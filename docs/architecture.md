## 2. 核心组件

### 2.1 Agent核心层

#### MacroInvestAgent
主控制器，协调各工作流执行完整的投资研究周期。

**职责：**
- 接收用户查询/指令
- 编排宏观研究、策略生成、回测验证工作流
- 管理上下文和记忆
- 生成最终投资报告

#### MacroResearchWorkflow
宏观研究工作流，负责收集和分析宏观经济数据。

**输入：** 关注的宏观指标列表
**输出：** 宏观环境评估、投资信号、建议

#### StrategyBuilderWorkflow
策略生成工作流，根据宏观信号构建投资组合策略。

**输入：** 宏观环境评估、投资信号
**输出：** 策略配置（资产、权重、调仓频率）

#### BacktestRunnerWorkflow
回测验证工作流，验证策略的历史表现。

**输入：** 策略配置、回测参数
**输出：** 回测结果、性能指标、可视化图表

### 2.2 MCP服务层

#### Macro Data Server
提供宏观经济数据查询服务。

**工具列表：**
- `get_china_macro_indicator`: 获取中国宏观指标
- `get_us_macro_indicator`: 获取美国宏观指标
- `get_global_commodity`: 获取大宗商品价格

#### Market Data Server
提供金融市场数据查询服务。

**工具列表：**
- `get_stock_history`: 获取股票历史行情
- `get_etf_history`: 获取ETF历史行情
- `get_market_index`: 获取市场指数

### 2.3 数据源层

| 数据源 | 用途 | 覆盖范围 |
|--------|------|----------|
| AkShare | 中国宏观经济、A股数据 | 中国 |
| Yahoo Finance | 美股、大宗商品、外汇 | 全球 |
| Tushare | A股高频数据、财务数据 | 中国 |
| 新闻API | 财经新闻、政策公告 | 全球 |

## 3. 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| Agent框架 | LangChain / 自定义 | 工作流编排、提示词管理 |
| MCP协议 | mcp (Python SDK) | 标准化数据接口 |
| 回测引擎 | bt (backtesting) | 轻量级、树状结构、适合Agent生成 |
| 数据处理 | pandas, numpy | 数据清洗、计算 |
| 可视化 | matplotlib, plotly | 收益曲线、回撤图 |
| 数据源 | akshare, yfinance | 免费、开源、覆盖广 |
| 配置管理 | pyyaml | YAML配置文件 |

## 4. 数据流

```
用户查询
  │
  ▼
Agent解析意图
  │
  ▼
MCP工具调用 → 宏观数据服务器 → AkShare/Yahoo Finance
  │
  ▼
原始数据 → 数据清洗 → 标准化数据
  │
  ▼
宏观分析 → 生成信号 → 策略构建
  │
  ▼
回测执行 → 性能评估 → 可视化
  │
  ▼
投资报告 → 用户
```

## 5. 扩展点

### 5.1 数据源扩展
- 添加新的MCP服务器
- 实现自定义数据获取工具
- 支持付费数据源（Bloomberg、Wind）

### 5.2 策略扩展
- 添加新的策略模板
- 实现机器学习因子模型
- 支持自定义策略节点

### 5.3 Agent能力扩展
- 多Agent协作（宏观Agent + 行业Agent + 个股Agent）
- 强化学习策略优化
- 实时交易对接

## 6. 安全与合规

- 数据源合规：使用公开、合法的数据源
- 风险提示：所有输出仅供参考，不构成投资建议
- 权限控制：MCP服务器访问控制
- 审计日志：记录所有Agent操作
