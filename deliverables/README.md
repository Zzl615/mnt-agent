# Deliverables & Insights

本目录存放 Money-AI 系统产出的最终投研报告和核心交易逻辑记忆。

## 📄 核心文件
- **MEMORY.md**: 系统的“长期记忆”中心。包含：
  - 用户实盘持仓与成本。
  - 核心分析框架 (9维度油轮框架等)。
  - 自动化报告的生成规范。
  - 用户交易偏好与止损止盈策略。

## 📊 报告格式
所有生成的报告遵循标准化 7 章结构：
1. **估值分析 (Valuation)**
2. **PEG 指标 (PEG Analysis)**
3. **投资组合建议 (Portfolio Suggestion)**
4. **仓位管理 (Position Management)**
5. **信号矩阵 (Signal Matrix)**
6. **风险控制 (Risk Control)**
7. **最终交易提案 (FINAL TRANSACTION PROPOSAL)**

## 📁 归档策略
- 命名规范：`YYYY-MM-DD-Subject.html/md`
- 临时或非标准化产出应移动至 `archive/` 文件夹。
