# Money-AI: 智能投研助理

Money-AI 是一个基于多智能体协作框架的自动化投资研究系统。它通过抓取和分析社交媒体、专业研报、视频速记等多元化数据，利用 12 个专业金融角色的协作，生成结构化的投资策略报告并管理交易逻辑。

## 📁 目录结构

```text
.
├── data/                   # 原始素材与中间处理数据
│   ├── chat-ocr/           # 财经群聊 OCR 结构化处理文档
│   ├── video-transcripts/  # 财经视频 AI 速记与字幕
│   └── 发财老博士/         # 核心投研笔记 (按日期归档)
├── deliverables/           # 最终投研产出 (Reports & Memory)
│   ├── MEMORY.md           # 长期记忆：记录用户持仓、分析框架、交易偏好
│   └── YYYY-MM-DD-Topic.md # 标准化投研报告 (HTML/MD)
├── docs/                   # 系统技术文档
│   ├── architecture.md     # 系统架构与多智能体工作流
│   ├── strategy-library.md # 策略库说明
│   └── risk-management.md  # 风控逻辑
└── README.md               # 项目总览
```

## 🚀 核心工作流

1. **数据采集**: 监控 `data/` 下的 OCR 记录、视频速记和专家笔记。
2. **多智能体分析**: 触发 12 个角色（策略专家、风控专家等）的 5 阶段工作流。
3. **报告生成**: 在 `deliverables/` 生成标准化 7 章投研报告。
4. **决策执行**: 根据 `MEMORY.md` 中的持仓和偏好，生成交易建议或执行逻辑。

## 📊 资源说明

- **chat-ocr**: 包含对高频财经群聊的结构化处理。
- **video-transcripts**: 包含宏观事件与机构调研的视频深度解析。
- **发财老博士**: 存放核心投研专家的早/午/晚盘分析、复盘笔记及系统日志。
- **deliverables**: 最终产出的标准化深度报告。
