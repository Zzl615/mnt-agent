# 投资笔记 (Investment Notes)

本目录存放个人的投资思考、盘后总结以及非结构化的投资笔记。

## 📝 内容建议
- **每日笔记**: 记录当下的市场观点与操作心态。
- **周度/月度报告**: 对一段时间内的市场走势进行深度总结与推演。
- **灵感草稿**: 尚未形成正式投研报告的原始想法。

## 📂 归档建议

### 命名规范
- **每日笔记**: `YYYY-MM-DD-daily.md` (例如 `2026-06-05-daily.md`)
- **周度报告**: `YYYY-MM-Wxx-weekly.md` (例如 `2026-06-W1-weekly.md`)
- **月度总结**: `YYYY-MM-monthly.md`

### 目录结构
建议按来源进行二级目录分类：
`data/investment-notes/[来源名称]/[文件名].md`

### 元数据
每份笔记建议包含 YAML Frontmatter 以便检索：
```yaml
---
date: 2026-06-05
type: daily
source: 发财老博士
tags: [AI, 芯片]
---
```
