# 发财老博士 投资笔记

本目录存放来自“发财老博士”相关的投资复盘笔记。

## 📌 来源简介
“发财老博士”是一位专注于宏观策略与产业趋势的深度分析者。其观点通常涵盖：
- **AI 产业链**: 算力、存储、应用、物理 AI 等。
- **先进制造**: 玻璃基板、半导体设备等。
- **宏观策略**: 资金面分析、高低切换路径、海外映射等。

## 📂 结构说明
- `YYYY-MM-DD-daily.md`: 每日盘后复盘笔记。
- `YYYY-MM-Wxx-weekly.md`: 周度市场战略复盘报告。

## 🛠️ 处理流程
1. 使用 `data/investment-notes/prompt/daily.md` 处理每日截图。
2. 周末汇总每日笔记，使用 `data/investment-notes/prompt/weekly.md` 生成周报。
